# 界面设计约定

收件台是操作型产品，视觉服务于查找邮箱、阅读来信和管理授权，不采用营销页的大幅标题或深色装饰区。

## 主题与组件

- 固定浅色：白色内容面板、浅灰侧栏和页面背景。系统切换深色时，页面及原生表单仍保持浅色。
- 以 `web/site.css` 中的语义变量作为唯一主题来源，不追加相互覆盖的主题片段。
- 青绿色只用于主操作、选中状态和必要反馈；账号使用淡色标识，同时保留名称文字。
- 中文正文使用本机中文字体，行高至少 1.5，无负字距；产品标题使用固定字阶。表格和统计数字使用等宽数字。
- 标准按钮与输入框高 40px，窄屏触控目标至少 44px；标签、输入与操作沿同一基线排列。
- 表格宽度不足时仅表格区域横向滚动；长邮箱地址在收件页自然换行，复制按钮独立保留。

## 交互约定

- 管理页与收件页自动刷新默认关闭，浏览器分别保存开启状态及间隔。
- 登录、提交、刷新等操作具有明确等待状态；等待时同时阻止鼠标、键盘和重复提交，结束或失败后恢复原控件状态。
- 原生弹窗提供取消、Escape 和可见焦点；提交期间保持弹窗，结果出来后继续显示确认信息或一次性凭证。
- 复制成功才显示“已复制”；剪贴板失败时提示手动操作。
- 邮件正文保持纯文本，不为视觉效果放宽内容安全策略。
- 分享弹窗明确显示天数选择及权限范围；生成后直接提供每个邮箱的可复制链接与到期时间。“分享管理”区分有效、已到期与已撤销；续期与重置链接是不同操作。
- 收件页的授权徽章显示实际有效期。链接自动登录前清除地址栏凭证；无效链接不展示此前会话的邮箱。到期清屏计时不属于自动刷新，不发起周期请求。

## 采用的设计准则

- [qiaomu-design 中文排版](https://github.com/joeseesun/qiaomu-design/blob/main/references/chinese-typography.md)：中文字体、行高、字重与数字排版。
- [Impeccable Operate](https://github.com/pbakaus/impeccable/blob/main/skill/reference/operate.md)：产品型界面、克制层级、一致控件与状态反馈。
- [Vercel Web Interface Guidelines](https://github.com/vercel-labs/web-interface-guidelines/blob/main/command.md)：语义表单、键盘焦点、可访问名称、内容溢出和减少动态效果。

这些准则作为设计参考，不自动复制营销布局、安装依赖或引入外部字体。更新需检查桌面、平板、手机、登录态、空态、错误态及等待态。
