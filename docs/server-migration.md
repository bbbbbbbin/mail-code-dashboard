3. 在离线副本上验证迁移转换：内部 ID 不重新编号，分组和标识不丢失，所有邮箱都带正确账号归属。
4. 停止对应源实例生成后，获取最终一致性快照；迁移器必须默认 dry-run、明确确认后才导入，非空目标拒绝覆盖。

6. 比较总数、地址集合、分组计数、标签、备注、历史记录；抽样检查收件。原来的“已使用”不推断成新的“已分发”，**迁移不生成 Token**。
